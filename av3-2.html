O que é K-Means Clustering?

K-Means é um algoritmo de aprendizado não supervisionado que agrupa dados em K clusters baseado na similaridade.

🎯 Objetivo

Particionar N observações em K grupos onde cada observação pertence ao cluster com a média mais próxima.

📊 Características

  • Tipo: Clustering (Agrupamento)
  • Categoria: Aprendizado Não Supervisionado
  • Complexidade: O(n × k × i × d)
  • Métrica: Distância Euclidiana

✅ Aplicações

  • Segmentação de clientes
  • Análise de mercado
  • Compressão de imagens
  • Detecção de anomalias

Como o K-Means Funciona?

1 Inicialização: Escolher K centróides aleatoriamente
2 Atribuição: Cada ponto é atribuído ao centróide mais próximo
3 Atualização: Recalcular os centróides como média dos pontos
4 Convergência: Repetir passos 2-3 até centróides não mudarem

📐 Fórmula da Distância Euclidiana

d(p, q) = raiz[(p1 - q1)² + (p2 - q2)² + ... + (pn - qn)²]

🎯 Objetivo do Algoritmo

Minimizar a soma das distâncias quadradas aos centróides

📂 2. Carregamento dos Dados

# Ler arquivo CSV df = pd.read_csv('medicamentos.csv') print(df.shape) # (41547, 6) print(df.head())

🔧 3. Limpeza de Dados

# Limpar coluna Preço df['Preco'] = df['Preco'].str.replace('R$', '') df['Preco'] = df['Preco'].str.replace(',', '.') df['Preco'] = pd.to_numeric(df['Preco']) # Preencher valores faltantes df['Preco'].fillna(df['Preco'].median(), inplace=True)

Implementação: Parte 2 - Pré-processamento

📊 4. Seleção de Features

# Selecionar features numéricas features = ['Quantidade', 'DoseValor', 'Preco'] X = df[features] # Remover NaN X = X.dropna() print("Dataset final:", X.shape[0], "registros")

⚖️ 5. Normalização dos Dados

# Normalizar features com StandardScaler scaler = StandardScaler() X_scaled = scaler.fit_transform(X) # Verificar normalização print("Média:", X_scaled.mean(axis=0)) print("Desvio:", X_scaled.std(axis=0))

❓ Por que normalizar?

  • Features têm escalas diferentes (1-6000 vs 0-5B)
  • K-Means usa distância Euclidiana (sensível à escala)
  • Garante que todas features tenham peso igual

Implementação: Parte 3 - K-Means

📈 6. Método do Cotovelo

# Testar diferentes valores de K inertias = [] silhouette_scores = [] for k in range(2, 8): kmeans = KMeans(n_clusters=k, random_state=42) kmeans.fit(X_scaled) inertias.append(kmeans.inertia_) score = silhouette_score(X_scaled, kmeans.labels_) silhouette_scores.append(score)

🎯 7. Aplicar K-Means Final

# K ótimo = 2 kmeans_final = KMeans( n_clusters=2, init='k-means++', n_init=10, max_iter=300, random_state=42 ) clusters = kmeans_final.fit_predict(X_scaled) df['Cluster'] = clusters
